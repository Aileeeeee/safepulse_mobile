# SafePulse — Android Studio + VS Code Setup Guide

## Prerequisites Checklist

Before anything, confirm you have these installed:

| Tool | Version | Check Command |
|------|---------|---------------|
| Node.js | 18 or 20 LTS | `node --version` |
| npm | 9+ | `npm --version` |
| Java JDK | 17 (LTS) | `java --version` |
| Android Studio | Hedgehog or newer | Open Android Studio → Help → About |
| VS Code | Latest | Open VS Code → Help → About |

---

## Step 1 — Install Java JDK 17

Android Studio requires JDK 17 specifically.

1. Download from: https://adoptium.net/temurin/releases/?version=17
2. Choose: **Windows x64 → .msi installer**
3. Install with default settings
4. Verify: open PowerShell and run:
   ```powershell
   java --version
   # Should show: openjdk 17.x.x
   ```

---

## Step 2 — Install Android Studio

1. Download from: https://developer.android.com/studio
2. Run installer → accept all defaults
3. On first launch, complete the **Setup Wizard**:
   - Choose **Standard** installation
   - Accept all license agreements
   - Let it download the Android SDK (takes 5–10 min)

### Configure Android SDK Path

4. In Android Studio: **More Actions → SDK Manager**
5. Note the **Android SDK Location** path (e.g. `C:\Users\YourName\AppData\Local\Android\Sdk`)
6. Set environment variables in PowerShell (run as Administrator):

```powershell
# Set ANDROID_HOME — replace the path with YOUR actual SDK path
[System.Environment]::SetEnvironmentVariable("ANDROID_HOME", "C:\Users\YourName\AppData\Local\Android\Sdk", "User")
[System.Environment]::SetEnvironmentVariable("ANDROID_SDK_ROOT", "C:\Users\YourName\AppData\Local\Android\Sdk", "User")

# Add platform-tools to PATH
$currentPath = [System.Environment]::GetEnvironmentVariable("PATH", "User")
[System.Environment]::SetEnvironmentVariable("PATH", "$currentPath;C:\Users\YourName\AppData\Local\Android\Sdk\platform-tools;C:\Users\YourName\AppData\Local\Android\Sdk\emulator", "User")
```

7. **Close and reopen PowerShell**, then verify:
   ```powershell
   adb --version
   # Should show: Android Debug Bridge version x.x.x
   ```

---

## Step 3 — Create an Android Virtual Device (AVD)

1. In Android Studio: **More Actions → Virtual Device Manager**
2. Click **Create Device**
3. Select: **Pixel 7** (or Pixel 6) → Next
4. Select system image: **API 34 (Android 14) — x86_64** → Download if needed → Next
5. AVD Name: `Pixel_7_API_34` → Finish
6. Click the **▶ Play button** to start the emulator
7. Wait for it to fully boot to the Android home screen before continuing

---

## Step 4 — Install Node.js

1. Download from: https://nodejs.org (choose **LTS version**)
2. Install with defaults — make sure "Add to PATH" is checked
3. Verify:
   ```powershell
   node --version   # v18.x.x or v20.x.x
   npm --version    # 9.x.x or 10.x.x
   ```

---

## Step 5 — Set Up the SafePulse Project in VS Code

### 5a. Open VS Code and install the React Native extension

Install these VS Code extensions:
- **React Native Tools** (Microsoft)
- **ESLint**
- **Prettier**

### 5b. Create fresh Expo project and copy SafePulse files

Open a new terminal in VS Code (`Ctrl + \``) and run:

```powershell
# Navigate to where you want the project
cd C:\Users\YourName\Documents

# Create a fresh Expo project with the exact same name
npx create-expo-app@latest safepulse --template blank-typescript
# When asked "OK to proceed?" → press Y

cd safepulse
```

### 5c. Copy the SafePulse source files

Now copy ALL files from the downloaded zip into this folder, **replacing** the files that were generated by create-expo-app. Your final structure should look like:

```
safepulse/
├── app/                    ← from zip (replace entire folder)
├── assets/                 ← from zip (keep this)
├── components/             ← from zip (new folder)
├── constants/              ← from zip (new folder)
├── hooks/                  ← from zip (new folder)
├── types/                  ← from zip (new folder)
├── app.json                ← from zip (replace)
├── babel.config.js         ← from zip (replace)
├── metro.config.js         ← from zip (replace)
├── package.json            ← from zip (replace)
└── tsconfig.json           ← from zip (replace)
```

### 5d. Install all dependencies

```powershell
npm install
```

Then install Expo-specific native modules:

```powershell
npx expo install expo-router expo-status-bar expo-haptics expo-location expo-linking expo-constants expo-splash-screen react-native-safe-area-context react-native-screens react-native-gesture-handler react-native-reanimated
```

---

## Step 6 — Run on Android Emulator

Make sure the Android emulator from Step 3 is **already running** (you should see the Android home screen).

Then in VS Code terminal:

```powershell
npx expo start --android
```

Expo will:
1. Start the Metro bundler
2. Detect your running emulator automatically
3. Install the Expo Go app on the emulator (first time only)
4. Open SafePulse in the emulator

### If emulator is not detected automatically:

```powershell
# Check emulator is visible to ADB
adb devices
# Should show: emulator-5554   device

# Then press 'a' in the Expo terminal to open on Android
```

---

## Step 7 — Hot Reload & Development

Once running:
- **Save any file** in VS Code → app reloads automatically
- **Shake the emulator** (or press `Ctrl+M` in emulator) → opens Expo Dev Menu
- Press `r` in the Expo terminal → force reload
- Press `j` → open debugger

## Common Errors & Fixes

| Error | Fix |
|-------|-----|
| `ANDROID_HOME not set` | Redo Step 2 env variables, restart PowerShell |
| `adb not found` | Add `platform-tools` to PATH (Step 2) |
| `SDK location not found` | Open Android Studio → SDK Manager → copy the path |
| `Emulator not detected` | Make sure emulator is fully booted, run `adb devices` |
| `Metro bundler port in use` | Run `npx expo start --port 8082` |
| `Cannot find module 'expo-router'` | Run `npm install` again |
| `Invariant Violation: "main" has not been registered` | Check `package.json` "main" is `"expo-router/entry"` |
| Java version wrong | Install JDK 17 exactly, not 11 or 21 |

## Quick Reference Commands

```powershell
# Start dev server
npx expo start

# Start and open directly on Android
npx expo start --android

# Clear cache if things look broken
npx expo start --clear

# Check connected devices
adb devices

# Kill all Metro processes if stuck
npx kill-port 8081
```
